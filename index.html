NASA Wallpaper Automation

Automated macOS wallpaper management system featuring two Python scripts that fetch stunning space imagery from NASA APIs. Both scripts feature intelligent history tracking to avoid duplicates, automatic high-resolution image downloads, and seamless wallpaper setting via AppleScript integration.
