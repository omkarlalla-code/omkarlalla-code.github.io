Project Overview

The ATIS METAR Weather Station is a comprehensive aviation weather monitoring system designed for professional aviation applications. Built using Raspberry Pi 4, ESP32 microcontroller, and advanced computer vision, this system provides real-time weather data, ATIS audio feeds, flight tracking capabilities, and innovative gesture-based control interface inspired by Microsoft Flight Simulator.

Raspberry Pi 4 ESP32 Microcontroller Python 3.9+ MediaPipe Computer Vision WebRTC Audio Streaming React.js Frontend WebSocket Real-time Aviation APIs

Core Features

Real-time METAR Data

Live weather monitoring from multiple airports with automatic updates every 5 minutes. Displays temperature, barometric pressure, wind speed/direction, visibility, and cloud conditions in aviation-standard format.

ATIS Audio Feeds

Streaming audio from airport Automatic Terminal Information Service broadcasts. Supports multiple airports simultaneously with clear audio quality and background noise reduction.

Gesture Control System

Advanced computer vision using MediaPipe for hands-free operation. Recognizes aviation-specific gestures for intuitive control without physical interaction with the interface.

Flight Tracking Integration

Real-time aircraft tracking using FlightRadar24 and FlightAware APIs. Displays live flight paths, aircraft information, and arrival/departure data with interactive mapping.

Radio Garden Integration

Access to global radio stations and aviation communications. Provides background audio and emergency frequency monitoring with clear reception quality.

Professional Aviation UI

Microsoft Flight Simulator-inspired interface with dark theme, aviation typography, and instrument-style displays. Optimized for 19" monitor with high contrast visibility.

Gesture Control Innovation

Aviation-Specific Gesture Commands:

Airport Navigation

  • Swipe Left/Right: Switch between airports
  • Point Up: Play/pause ATIS audio
  • Point Down: Stop all audio feeds
  • Circular Motion: Refresh weather data

Flight Operations

  • Make Fist: Select aircraft on radar
  • Open Palm: Return to main menu
  • Thumbs Up: Zoom in on flight path
  • Thumbs Down: Zoom out from display

Computer Vision Implementation

The gesture recognition system processes 30 frames per second using Google's MediaPipe framework. Hand landmark detection achieves sub-200ms response times with 95% accuracy in controlled lighting conditions. The system adapts to different users and lighting conditions through continuous calibration.

Technical Implementation

Hardware Configuration

ESP32 Antenna System

  • Mounted on balcony beam for optimal reception
  • Weather-resistant housing with proper grounding
  • WiFi connectivity to main terminal
  • Real-time data transmission to Raspberry Pi

Raspberry Pi Terminal

  • Raspberry Pi 4 (4GB RAM) main processing unit
  • 19" monitor for professional aviation display
  • USB webcam for gesture recognition input
  • Audio output for ATIS and radio feeds

Software Architecture

The system uses a modular Python backend with React.js frontend, connected via WebSocket for real-time communication. MediaPipe handles computer vision processing while separate microservices manage weather data collection, audio streaming, and flight tracking integration.

Development Challenges

Technical Challenges Overcome:

  • Real-time Gesture Processing: Optimizing MediaPipe for 30fps on Raspberry Pi hardware constraints
  • Audio Stream Management: Handling multiple simultaneous ATIS feeds without latency or dropouts
  • API Rate Limiting: Efficient caching and request management for aviation data APIs
  • Weather Antenna Reception: Optimizing ESP32 positioning and signal processing for reliable data
  • UI Responsiveness: Maintaining smooth user interface while processing intensive computer vision
  • Cross-platform Integration: Seamless communication between ESP32, Raspberry Pi, and web interface
